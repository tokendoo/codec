# tokendoo

Lossless structural compression for JSON that targets **tokens**, not bytes.
Symbol spellings are chosen so each control symbol encodes as a single token in a
measured tokenizer vocabulary. The transforms are deterministic, invertible, and
small enough to run anywhere Rust runs.

## Install and compress

```bash
cargo add tokendoo
```

```rust
use tokendoo::{compress, decompress};

fn main() -> Result<(), tokendoo::CodecError> {
    let input = r#"{"users":[{"id":1,"name":"a"},{"id":2,"name":"b"}]}"#;
    let result = compress(input)?;
    let round_trip = decompress(&result.compressed, &result.dictionary)?;
    assert_eq!(
        serde_json::from_str::<serde_json::Value>(input).unwrap(),
        serde_json::from_str::<serde_json::Value>(&round_trip).unwrap()
    );
    Ok(())
}
```

Until the crate is on crates.io, depend on the git source:

```toml
tokendoo = { git = "https://github.com/tokendoo/codec" }
```

## Round-trip guarantee

Round-trip is defined over `serde_json::Value` equality after parse, not over
raw input bytes. Property tests and regression fixtures enforce
`decompress(compress(x)) == x` on that basis.

Verify from a clone:

```bash
cargo test -p tokendoo
```

## Reproduce the published figures

Exact `cl100k_base` token counts live in `docs/context/`. From a clean clone:

```bash
cargo run -p tokendoo-bench --release --bin tokendoo-bench
cargo run -p tokendoo-bench --release --bin tokendoo-alphabets
cargo run -p tokendoo-bench --release --bin tokendoo-calibrate
```

These rewrite `docs/context/tok-002-measurements.*`,
`docs/context/tok-007-alphabets.*`, and
`docs/context/estimator-calibration.json`. Diff against the committed files;
the exact counts must match.

The fixture corpus is entirely synthetic. It is generated by committed code in
`crates/tokendoo-bench/src/fixtures.rs` (seeded RNG, no network, no PII).

Representation choice on the published corpus moved the median token ratio by
twenty-four points across hand-written alphabets. Vocabulary-derived tables for
`cl100k_base`, `o200k_base`, and a Llama tokenizer are included; the default
shipping alphabet is the cl100k-derived table. Accuracy of the in-crate token
*estimator* was calibrated against exact cl100k counts only.

## What this repository does not contain

- The hosted Worker / API service.
- The comprehension evaluation harness (whether a model answers as well on
  compressed input is a separate measurement and is not claimed here).
- Runtime-swappable alphabet tables. Derived tables are compiled into the crate
  today; loading versioned tables at runtime is future work.
